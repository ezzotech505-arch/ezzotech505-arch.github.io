Ezzo PS Emulator

High-Performance PlayStation 1 Emulator • Dynamic Core Switching
Package Name: com.ezzopsemu | Version: 1.0.0 | Target OS: Android 8.0 (API 26) or higher

Overview

Ezzo PS Emulator is a high-performance, precision PlayStation 1 (PS1/PSX) emulator designed for Android devices. Featuring native ARM64 dynamic recompiler technology, multi-core architecture support (PCSX ReARMed & Mednafen), and low-latency audio via Google Oboe, it delivers an authentic classic gaming experience with modern enhancements.

Key Features

  • Multi-Engine Support: Dynamic switching between PCSX ReARMed (high performance dynarec) and Mednafen (cycle-accurate) cores.
  • Oboe Ultra-Low Latency Audio: Powered by Google Oboe to ensure crisp, synchronized audio playback without stutter.
  • Customizable Virtual Controller & Gamepad Support: Full support for on-screen touch controls with customizable opacity, haptic feedback, and Bluetooth/USB physical gamepads.
  • Display & Performance Enhancements: Hardware accelerated OpenGL ES rendering, CRT scanline filter emulation, and custom aspect ratio controls.
  • Safe Storage Access (SAF): Strict adherence to Android's Storage Access Framework, giving you full control over game discs, multi-disc PBP/CHD images, BIOS files, and save states without invasive permissions.
