Ezzo DevLens

Integrated Diagnostic Suite for Android Developers, QA, & Power Users
Package Name: com.ezzodevlens | Version: 1.2.0 | Target OS: Android 8.0 (API 26) or higher

Overview

Ezzo DevLens is an all-in-one diagnostic and benchmarking tool designed for Android engineers, QA teams, and tech enthusiasts. Built with a clean dark aesthetic, it delivers instant access to low-level hardware specs, screen density metrics, and network health without bloat.

Key Features

  • Hardware & SoC Inspection: Real-time inspection of Chipset (SoC), CPU core architecture, ABI support, Android build info, security patch levels, and battery health/voltage/temperature.
  • Screen Metrics & DP Converter: Displays physical resolution, aspect ratio, density (DPI), xdpi/ydpi, and refresh rates with automatic px-to-dp conversion across all density buckets (mdpi – xxxhdpi).
  • Standalone Network Diagnostics (NetCheck): Direct on-device testing of TCP ports, ICMP/Socket Ping, DNS resolution, TLS/SSL certificate expiry, and HTTP status codes — with one-tap cURL command generation.
  • App Package Inspector: Quickly query installed packages, version codes, signing key hashes, and target SDK levels.
  • One-Tap Markdown Export: Copy comprehensive system reports formatted in clean Markdown to your clipboard — perfect for filing GitHub Issues or debugging logs.
